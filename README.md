# 🎮 Hangman Game (React)

An interactive Hangman game built using React.js where users guess letters to reveal a hidden word before running out of attempts.

---

## 🚀 Live Demo
https://hangmanpro-five.vercel.app/

---

## ✨ Features

- 🎯 Random word generation  
- ⌨️ Interactive keyboard input  
- ❌ Limited attempts system  
- 🏆 Win/Loss detection  
- 🔄 Restart game functionality  
- 📱 Responsive design  

---

## 🛠 Tech Stack

- React.js  
- JavaScript (ES6+)  
- CSS / Tailwind (if used)
